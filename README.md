# ReAct-Agent-RAG
RAG + Agent智能问答系统，支持ReAct循环、多工具协作、多轮记忆、可观测性展示。  
**技术栈**: FastAPI + Ollama + Chroma + LangChain(ReAct)

## 📋 项目简介
系统结合了 RAG（检索增强生成）和 Agent（智能体）能力，支持多轮对话、工具调用、缓存优化和全链路可观测性。  
**核心亮点**：
- 🔍 **RAG能力**：本地文档检索 + 向量数据库
- 🤖 **Agent能力**：ReAct循环，3个内置工具（知识库检索/天气查询/数学计算）
- 🧠 **多轮记忆**：保留最近3轮对话上下文
- 📊 **全程可视化**：前端展示思考过程、工具调用、缓存命中、性能指标
- 🏗️ **工程化**：模块化设计 + 日志追踪 + 容错机制 + Docker部署

## 🛠️ 技术栈
| 组件 | 技术 |
|------|------|
| 后端框架 | FastAPI |
| 大模型 | Ollama |
| 向量数据库 | Chroma |
| Agent框架 | 自研 ReAct 实现 |
| 前端 | 纯HTML + CSS + JS (单文件) |
| 容器化 | Docker + Docker Compose |
